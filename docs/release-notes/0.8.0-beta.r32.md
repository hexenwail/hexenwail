Compiled Hexen II and Portals of Praevus gamecode ships in both zips and loads automatically.

### Changes from [0.8.0-beta.r31](https://github.com/hexenwail/hexenwail/releases/tag/0.8.0-beta.r31)

- Renamed the Windows executable to `hexenwail.exe`, so it can sit beside a vanilla `glh2.exe` without replacing it; crash reports are now written to `hexenwail.RPT`
- Added a read-only `hexenwail` cvar carrying the engine version as a number, so HexenC mods can detect this engine with `cvar("hexenwail")`; it reads 0 on every other engine
- Added "Weapon Kick" (off / vanilla / smooth) to Game Options, exposing `v_gunkick` as a motion-sickness opt-out
- Changed liquid ripples to move surfaces downward only, so water rims no longer float above sloped floors
- Fixed `SV_CheckBottom` testing a fixed clip-hull box instead of the monster's own bounding box when checking for ledges
- Added drawing of HexenWorld temp entities, including the grenade-smoke and purifier trails
- Fixed the HexenWorld client clock not advancing on every entity update
- Fixed HexenWorld mods that swap weapon models printing "no such frame" every frame; invalid received frames are now clamped
- Ported more of the engine to the consolidated Rust library: `cvar`, `zone`, `cmd`, `quakefs`, and the HexenWorld and Hexen II network transport layers; C fallback build paths are retained

This rolls up 26 commits since r31. Documentation, CI, test and internal refactor commits with no user-visible effect are omitted above.
