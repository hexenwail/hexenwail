Compiled Hexen II and Portal of Praevus gamecode ships in both zips and loads automatically.

❗ **Note**: the Linux client binary is now `hexenwail`, not `glhexen2`. Scripts and shortcuts that launch `glhexen2` need updating; the Windows build was already `hexenwail.exe`.

### Changes from [0.8.0-beta.r34](https://github.com/hexenwail/hexenwail/releases/tag/0.8.0-beta.r34)

- Added loading of Quake BSP29 and BSP2 maps: the map draws and the player collides with it. Quake textures go through Hexen II's palette, Quake-only entities are dropped, and a Quake player start can sit 24 units too high
- Added demo rewind: hold the left arrow during playback to rewind at 5x (Shift/Ctrl quarter it); the demo bar shows `<<`
- Added an AppImage, the Linux release in one runnable file; it finds game data beside itself or in `~/.hexen2/data1`, and offers the free demo when it finds neither
- Added cube shadow maps for dynamic lights on desktop GL, so a torch no longer lights what a wall hides from it
  - `r_dlight_occlusion` (default: 2 on desktop, 1 on GLES/WebGL2 and the software renderer; 0 is vanilla), also in Options > Display > Misc as "DLight Occlusion"
  - `r_shadow_resolution` (128), `r_shadow_maxlights` (8), `r_shadow_filter` (1), `r_shadow_updates` (2), `r_shadow_bias` (1) and `r_shadow_casters` (1; 2 lets alias models cast), all set by the Display presets
  - Fixed a dynamic light lighting a face from behind, and brush entities that move or turn being lit in the wrong place
- Added `r_ssao` (default: 0; 1-3 low to high), contact occlusion under monsters, items and doors standing on the world, ported from [vkQuake](https://github.com/Novum/vkQuake); `r_ssao_radius` (32) and `r_ssao_strength` (1.0) tune it
- Added `r_oit 2`, moment-based order-independent transparency from vkQuake; `r_oit 1` is unchanged and the default is still 0
- Added `r_gpulightstyles` (default: 1): flickering and switchable lights animate in the world shader instead of rebuilding and re-uploading lightmaps every frame (desktop GL)
- Added `r_softemu_spans` (default: 0), "Retro Spans" in the Rendering menu, which draws world texture like the 1997 span rasteriser's every-8-pixels perspective correction
- Added `sv_autoload` (default: 2), as in Ironwail: dying loads the last save made or loaded on the current map; 0 off, 1 asks, 3 on any restart
  - The Maps browser now asks for a skill after picking a map, and offers "Resume last game" when that map has an autosave
- Added `cl_startmenu` (default: 1), Ironwail's toggle; 0 starts at the console or the demo loop instead of the main menu
- Added `joy_always_active` (default: 0), as in Ironwail: at 0, rumble and gyro steering act only while the gamepad is the device last used; 1 keeps them on
- Added `sv_maxdatagram` (default: 0, no cap) to cap the per-frame datagram below the path MTU; about 1400 suits real links
- Raised the `max_edicts` default to 16384 (ceiling 32000; it could previously only lower the old 8192 limit), and sounds from entities past 8192 now reach the client
- Added `scr_sbaralpha` (default: 1) on GL, which fades the bottom status bar, so the HUD transparency row in the menu now does something
- Added `r_showtris` outlines for alias models, sprites, particles and the viewmodel
- Added `_glow` / `_luma` fullbright skins for MD3 and MD5 models, and instanced drawing and glow for MD3 models
- Added fog on the scrolling sky through `r_skyfog` (default: 0.5) or a worldspawn `skyfog`, and the skybox now draws at `r_skyfog` 1 instead of going black
- Added Show Clock, Show Speed and Center Print BG to the software renderer
- Added an experimental SDL_GPU renderer backend, opt-in with `-gpu` and still in progress (#340); GL remains the default
- Changed `jsh2colour` to give `light_candle` and `light_lantern` orange light, from [sezero/uhexen2#80](https://github.com/sezero/uhexen2/pull/80) by James Le Cuirot
- Fixed brush entities with an `abslight`, such as romeric6's breakable pillars, drawing at half the brightness they were lit for
- Fixed a `misc_modelpimp` with spawnflags 4 + 16 (glow orb, this entity only) drawing no orb; it now draws at the controller (#523)
- Fixed a `misc_modelpimp` with spawnflags 8 + 16 (cast light, this entity only) casting no light; it now lights from the controller (#525)
- Fixed `sv_gameplayfix_elevators` never lifting the rider of the platform carrying it
- Fixed the Paladin's purifier missiles, and anything else spawned during the physics frame, appearing ahead of where they were fired
- Fixed alias models past the 256th drawing as nothing (Storm over Thyrion's courtyard loads 351), and models being handed another model's GPU mesh
- Fixed multi-skin models flood-filling skin 0 once per skin and never the others, which bled background colour into the edges of about 30 retail models
- Fixed `r_lerp_autodetect` turning off interpolation for a whole model over one violent animation; it now snaps only the pose pairs too far apart
- Fixed `r_wateralpha` not reaching `EF_TRANSPARENT` model skins until a map reload
- Fixed `contrast` darkening the frame; it now multiplies, clamped 1-2, as in Ironwail
- Fixed `r_fastsky` leaving the sky black; it fills the classic sky and skyboxes with a flat colour, or the fog colour
- Fixed particles moving, and snow falling forever, while the game is paused
- Fixed `vid_restart` leaving brush-model textures as flat coloured blocks, and dropping replacement textures
- Fixed `r_entdist` not culling instanced alias models
- Fixed a mod with a large `gfx.wad` aborting at startup
- Fixed `csprogs.dat` images built by the old hcc reading past the end of their globals
- Fixed dedicated servers running out of memory on big maps: `h2ded` and `hwsv` now start with the client's 512 MB heap, and the error names `-heapsize`
- Fixed a server crash on an entity with a NaN bounding box
- Made 320x200 a valid video mode again, with a main menu that fits in it
- Made the `Gamecode:` line name every Raven release it knows (1.03, 1.08 to 1.11, Portals 1.12 and 1.12a, and the 1997 demo) instead of "Third-party"
- Made the 1997 demo and HexenWorld's `pak4` run as pk3s, and `maplist` and the other name listings see inside pk3s; added `pak2pk3.py`, which converts a retail gamedir's paks to pk3s
- Ported eight Portal of Praevus gamecode fixes from [jsHexen2-progs](https://github.com/KoMiKoZa/jsHexen2-progs)
- Menus:
  - Fixed clicks on confirmation prompts: only a click on an answer row answers, it lands once, and a click no longer quits from the quit prompt
  - Fixed a menu losing the mouse pointer to the game while it is open
  - Fixed the main-menu version line printing over the renderer name on the software renderer
  - Fixed long mod titles cutting off the same way, so sequels like "Mission Pack by Rino" and "Mission Pack by Rino 2" are told apart
  - Added one-line notes under the Options rows whose names do not explain them
  - Greyed out Mods on the demo, and made the `game` command refuse mods without the full game, as `-game` already did
  - Renamed "Weapon Kick" to "Screen Shake", since it covers every server-driven view shake
- HexenWorld:
  - Fixed `hwsv` not loading the `hwprogs.dat` shipped beside it
  - Fixed `svc_particle2/3/4` effects drawing as the wrong particle (grenade smoke as darken, red fire as snow)
  - Moved `hwmaster`'s `filters.ini` under `XDG_CONFIG_HOME`
- Web / PWA:
  - Made the player page open on the game, laid out like [quake-srp](https://quake-srp.pages.dev)'s, instead of a launcher of panels
  - Added a bundled General MIDI SoundFont (TimGM6mb), so MIDI music plays without importing one, and import of your own SoundFont
  - Added importing a mod as the `.zip` it was downloaded as, and launching Portal of Praevus from the launcher
  - Made the web client start with mouse look on (the desktop default is unchanged)
  - Fixed the phone look pad, which now turns the camera at a usable rate
  - Fixed WebGL2 GL errors, OIT under MSAA, and black screenshots
  - Fixed touch controls not coming back after a keyboard hid them, and SDL's "Pointer is already locked." messages
  - Fixed importing the full game leaving the demo's loose files to override it, save-bundle Merge skipping new slots, and the launcher forgetting a mod chosen in game
  - Added the demo playback bar to the software renderer
- Linux packaging:
  - Fixed the Linux zip and AppImage failing to start on a host missing an optional audio or display library (such as `libdecor-0.so.0`)
  - Removed libsndfile from the Linux bundle; SF3 soundfonts decode through libvorbisfile in the bundle and the Flatpak
- Updated the Windows build's SDL3 from 3.2.12 to 3.4.12
- Improved the software-emulation palette lookup to Ironwail's 128³ grid, which removes a colour quantisation step ahead of the palette match
- Moved more of the server (world, physics, monster movement and `sv_main`) to Rust behind differential tests

This rolls up 166 commits since r34. Documentation, CI, lint, test and internal refactor commits with no user-visible effect are omitted above.
