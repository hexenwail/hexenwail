### Changes since [0.7.8-beta.r7](https://github.com/hexenwail/hexenwail/releases/tag/0.7.8-beta.r7)

This is a two-month rollup, not a diff against yesterday's tag. `0.7.9-beta.r4` through `r14` were an emergency patch train tagged within the last two days to fix a Windows savegame regression and a handful of smaller bugs; every one of those fixes is folded into the list below. The last tag that meaningfully predates this whole window is `0.7.8-beta.r7` (June 12), so it's the honest comparison point rather than `0.7.9-beta.r14`.

- Started shipping compiled gamecode with every release. CI now builds all four HexenC trees (Hexen II, Portals, HexenWorld, Siege) with `hcc` on every push, so a `.hc` fix is no longer inert — the Hexen II and Portals `progs.dat`/`progs2.dat` are staged beside the engine binary and loaded automatically, with nothing for the player to copy. Added `-vanillaprogs` to opt out and run the game's own progs instead
- Added a startup `Gamecode:` line naming the loaded progs file, its on-disk path, and its CRC, so a bug report can say which gamecode produced it
- Fixed `DropBackpack` silently deleting backpacks that held only mana or health, with no console message and nothing even under `developer 1`. Any co-op or deathmatch death carrying both mana types lost its drop outright; `CLASS_GRUNT` (archers) hit the case on roughly a quarter of drops
- Reverted the Crusader's Glyph of the Ancients to Raven's retail behavior — it drops and detonates on whoever is standing on it, caster included. Two earlier local changes had made it land safely at the caster's feet or orbit harmlessly; both premises turned out to be wrong once checked against retail and Storm Over Thyrion bytecode, and neither was ever a good idea for a deathmatch weapon
- Added MSAA support to order-independent transparency, matching Ironwail
- Added underwater caustics on alias models (previously world geometry only)
- Added a bicubic lightmap filter (`r_lightmap_bicubic`) to soften Hexen II's coarse 16-luxel lightmap grid on large flat-lit walls; bilinear stays the default
- Added `gl_overbright_models 2` to let alias-model lighting reach the same brightness ceiling as world geometry
- Added `r_alias_minlight` (default 24), an Ironwail-style RGB floor so alias models don't render solid black in unlit spots
- Changed map leak pointfiles to draw as a chain of animated direction arrows instead of a flat dotted trail of particles
- Changed `r_lerpmodels` to default off; the Crunchy and Retro presets force it off regardless
- Added flipbook alias-model auto-detection so sheet-style animations (flames, waterfalls, explosions) stop being smoothed like a deforming mesh, without hand-maintaining a model whitelist
- Added mod-supplied `bindlist.lst` support so a mod can list its own bindable commands in the Key Setup menu instead of only documenting console commands
- Allowed the Demoness class in the original campaign when Portals of Praevus is installed, not just in the New Mission
- Fixed a use-after-free crash on changelevel (reproduced on Blackmarsh → Barbican): a connected client's inventory-page pointer survived into the new map's hunk after the old array was freed and reallocated underneath it
- Fixed the background save worker racing the main thread, and fixed a shared static buffer in the Windows UTF-8/UTF-16 path conversion that could corrupt a savegame copy
- Fixed the engine crashing (or in rarer cases running corrupted bytecode) on a truncated `progs.dat`/`csprogs.dat`; both are now bounds-checked before anything reads or byteswaps their lumps
- Fixed a crash on BSP entity strings that landed exactly on a hunk allocation boundary, where the string wasn't NUL-terminated on disk and downstream parsers walked off the end
- Fixed a regression, present since 0.7.8-beta.r29, where `GL_DITHER` was force-enabled at every startup and regressed alpha-test cutouts on some GPUs; the cvar and all its plumbing are removed
- Fixed portals being added to the filesystem search path twice under `-game`/`-mod`, wasting a file descriptor and a pak hash table per launch
- Fixed two rounds of puzzle-piece hitbox hacks that had been silently deleting map items (e.g. Storm Over Thyrion's Green Key) by force-widening their physics bounds; both hacks are removed, since the underlying "puzzle pieces stay zero-sized" premise was wrong
- Fixed archived cvars and rebinds being lost on crash or Alt-F4 — `config.cfg` now flushes during play, not only on clean shutdown
- Fixed `Sys_rename` on Windows to replace an existing destination like POSIX `rename`, closing a window where a crash between delete-old and rename-new could leave no `config.cfg` at all
- Fixed engine defaults being layered on gamecode's unused `default.cfg` copies instead of the one actually shipped inside retail `pak0.pak`, which had made a config fix look landed while doing nothing in the field
- Fixed a 25-bug backlog surfaced by an audit of the GL 4.3 pipeline: out-of-bounds vertex/index writes on malformed alias models, a stale-buffer bug that mis-targeted `glBufferSubData`, wrong-texture sampling after a context restore, swapped OIT sampler units, MD5 quaternion parsing, several small leaks, and more
- Fixed several lightmap/world-cull crashes and regressions: GPU culling running without a lightmap atlas, lightmap UVs not being re-baked on a video restart, and large maps hitting hard lightmap-page limits that made them fatal to load
- Fixed the Windows MIDI callback calling multimedia functions from Windows' own callback thread, which MSDN forbids and which could deadlock or corrupt state
- Fixed FluidSynth on Linux opening its own separate audio driver instead of routing through the engine's SDL mixer, which could fail silently inside the Flatpak sandbox and kill music while sound effects kept working
- Fixed MIDI being dead on bare Linux systems (Steam Deck, fresh installs) with no system soundfont; the engine now also looks next to its own binary and bundles a General MIDI soundfont in the Flatpak
- Added `libTiMidity` as a real fallback MIDI synth for builds with no FluidSynth (previously dead code); FluidSynth still takes priority wherever it's present
- Added a band-limited resampler (`snd_resample`, opt-in) that replaces nearest-sample resampling for loaded sound effects with a windowed-sinc filter, removing audible aliasing/imaging on the common 11025→44100 upsample
- Fixed the Steam Deck/portable Linux build missing its bundled shared libraries at the runtime path the binary actually looks for, and fixed a controller quit / D-pad double-input bug
- Made `svc_skybox` and `svc_mod_name` carry real values instead of an empty stub, ending the "Ignored server msg 54/55" spam under `developer 1`
- Raised `MAX_SOUNDS` from 512 to 1024 behind protocol 21 for large hubs approaching the old sound-precache ceiling, and fixed several related precache bugs (a packet desync on sound-index overflow, missing bounds checks, dead loop counters)
- Added a self-reporting crash handler and debug symbols to the Windows build, so a crash produces a `glh2.RPT` naming the source file and line instead of nothing past the last console print
- Added a one-command demo-data fetch helper so a new user doesn't need to already own a 1997 copy of the game to try the engine
- Removed the dead scaffolding from an NVIDIA screen-door investigation that ran ~29 speculative builds: four short-lived cvars (`r_alias_fullbright`, `r_alias_nofog`, `r_alias_r6_mode`, `r_alias_stochastic_alpha`) and their full plumbing, none ever a shipped default — safe to ignore if they show up in old notes or configs
- Removed the non-functional bindless-texture scaffolding (it never executed on any hardware; its entry points were permanently null)
- Removed 2,877 lines of dead code (`engine/h2shared/model.c` and its orphaned header) that compiled into no build target and had drifted into a third, wrong answer for alias-model physics bounds
- Added `tools/qcdis.py`, a `progs.dat` disassembler, plus a headless analysis harness, so "does our HexenC match the bytecode players actually run?" stays a cheap question to ask
- Restored the tester-build CI workflow, lost when its source branch was deleted

This rolls up 265 commits since June 13. About 150 of those were issue-tracker bookkeeping, documentation, or pure internal refactors with no user-visible effect and are omitted above.
