Compiled Hexen II and Portals of Praevus gamecode ships in both zips and loads automatically.

### Changes from [0.8.0-beta.r30](https://github.com/hexenwail/hexenwail/releases/tag/0.8.0-beta.r30)

- Fixed the `quit` console command to quit directly; the confirmation prompt remains in the menu
- Fixed `vid_restart` retaining GL object names from the destroyed context
- Fixed GL buffer updates using a stale cached binding after other engine code changed the generic buffer binding
- Restored vanilla's `r_wateralpha` default so teleporter shells remain translucent
- Fixed HexenWorld effect messages consuming the wrong payload size, which could discard the rest of a packet
- Built HexenWorld and Siege string tables into the engine as a fallback, so a legacy install no longer needs a separately copied `strings.txt`
- Added inline progress for HexenWorld downloads in the client
- Ported more engine utilities to the consolidated Rust library, including link operations, message I/O, string helpers, Huffman decoding and WAD loading; retained C fallback build paths

This rolls up 25 commits since r30. Documentation, CI, test and internal refactor commits with no user-visible effect are omitted above.
