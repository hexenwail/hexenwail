### Changes from [0.8.0-beta.r29](https://github.com/hexenwail/hexenwail/releases/tag/0.8.0-beta.r29)

- Added HexenWorld multiplayer support to the unified multiplayer menu. The client now joins Hexen II or HexenWorld servers from one flow, detects which protocol a server actually speaks after the initial connection, and mounts the server's selected gamedir before loading its map
- Added HexenWorld client presentation: remote players, Raven projectiles, missiles, particles, persistent effects, viewmodel feedback, player names and indexed server messages now render and print correctly
- Added the maintained HexenWorld dedicated server (`hwsv`) to the build, with a smoke test that exercises connecting, downloading, signon and live map changes
- Fixed HexenWorld networking failures that could leave a live-session net icon on screen, discard temp-entity packets, overflow a netchan without explaining why, or decode malformed/oversized entity streams unsafely
- Fixed HexenWorld downloads and content lookup: the client mounts HexenWorld below mods, receives its `strings.txt` tables in the shipped gamecode, selects the server gamedir's string table, and reports a missing world map rather than a misleading submodel error
- Added mouse dragging for menu sliders and the mod-list scrollbar, and fixed menu pointer coordinates at non-native canvas sizes
- Added `snd_filterquality`, selecting the audio resampler quality
- Added MD3 material maps on alias-model skins
- Improved renderer and platform compatibility: desktop GL calls now go through the loader, texture LOD bias stays on the desktop GL tier, model effect flags work in the software renderer, and macOS has its own build path
- Fixed demo playback without a live socket, multiplayer entity transparency, and image-dump memory safety
- Improved the Web build to precache the complete shell import graph and keep web test assets out of GitHub Pages

This rolls up 68 commits since r29. Documentation, CI, test and internal refactor commits with no user-visible effect are omitted above.
