### Changes since [0.8.0-beta.r31](https://github.com/hexenwail/hexenwail/releases/tag/0.8.0-beta.r31)

The `0.8.0-beta.r32` release was withdrawn, so this compares against `0.8.0-beta.r31`, the previous published release.

- Added HexenWorld's temporary-entity effects, so deathmatch and Siege draw the gibs, impacts, chunks, teleport flashes and flying weapon effects they were receiving and discarding, sounds included; HexenWorld's grenade-smoke and purifier trails are drawn too
- Added "Weapon Kick" to Game Options (off / vanilla / smooth), which brings `v_gunkick` (default: 2, smooth) within reach of the motion-sickness opt-out it exists for
- Added the `hexenwail` cvar for HexenC mods, carrying the engine version as a number — 80033 here — so `cvar("hexenwail") >= 80031` gates engine-specific content on every Hexen II engine, including the ones that number `checkextension()` differently
- Fixed the water ripple lifting a liquid's rim off a sloped floor and leaving the edge floating; it now moves downward only, so the rim sinks into the slope instead (reported by Tome of Power Abuser)
- Fixed monsters testing whether they stood at an edge against a fixed clip hull rather than their own bounding box, which let walkers step off ledges they should have refused
- Fixed HexenWorld's client clock not advancing on every entity update
- Fixed HexenWorld model frames arriving off the wire out of range and being used unchecked
- Fixed the browser build's menu confirmation prompts hanging forever: the keypress wait blocked inside a wasm frame, so no key could ever be delivered
- Ported Hexen II's transport layer to the consolidated Rust library and lifted its Linux-only restriction, so macOS and BSD build it too; HexenWorld's transport and channel layer, and the `cvar`, `zone`, `cmd` and `quakefs` subsystems, moved to Rust in the same run
- Made the build count CPUs with `getconf` rather than `nproc`, which is absent on macOS and BSD, where it silently left `make -j` with no limit and forked a compiler per source file
- Shipped `hexenwail.exe` beside vanilla's `glh2.exe` on Windows

This rolls up 31 commits since r31. Documentation, CI, test and internal refactor commits with no user-visible effect are omitted above.
