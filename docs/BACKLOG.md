items that were **not** migrated to GitHub Issues, one line each.  Anything
actively being worked on lives in GitHub Issues instead.

The original ids are kept because commit messages, code comments and the docs
under `history/` reference them.  They are breadcrumbs into the reasoning behind
a change, not live tickets -- there is no tracker to look them up in.

If one of these becomes real work, open a GitHub issue for it and delete the line
here.
